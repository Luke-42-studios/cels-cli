# Plan 02-01: `cels init <name>` — Non-Interactive Project Scaffolding

## Goal

Add a `cels init <name>` subcommand to cels-cli that creates a new CELS project directory with all files needed to compile and run immediately. When no subcommand is given, the CLI launches the TUI as before.

## Context

- The cels library ships a universal `main()` in `src/backends/main.c`. Static linkers skip it when the binary defines its own `main()`, so cels-cli can define a custom `main()` that handles subcommands before optionally delegating to the CELS runtime.
- Generated projects fetch CELS core via FetchContent and include `CelsDeps.cmake` for module management.
- FR-01.1 through FR-01.4 and FR-01.6 are P0 requirements. FR-01.5 (`--backend` flag) is P1, deferred.

## Requirements Covered

| ID | Requirement |
|----|-------------|
| FR-01.1 | `cels init <name>` creates directory with CMakeLists.txt, src/main.c, .gitignore |
| FR-01.2 | Generated CMakeLists.txt fetches CELS core via FetchContent, includes CelsDeps |
| FR-01.3 | Generated main.c contains a working CEL_Build with one CEL_Composition |
| FR-01.4 | `cels init <name> && cd <name> && cmake -B build && cmake --build build` succeeds |
| FR-01.6 | Generated .gitignore excludes build/, .cache/, compile_commands.json |

## Design

### CLI Entry Point

Replace `CEL_Build(CLI)` with a custom `main()` that:
1. Checks `argc` for subcommands (`init`, `--help`, `--version`)
2. If `init <name>` is found, run scaffolding and exit
3. If no subcommand (or TUI mode), call `Engine_Startup() -> CELS_BuildInit() -> cels_run_providers() -> Engine_Shutdown()`

The `CEL_Build(CLI)` macro stays but is renamed to a callable function since we no longer use the universal main. We define `CELS_BuildInit()` ourselves.

### Generated Project Structure

```
<name>/
  CMakeLists.txt    -- FetchContent(cels), include(CelsDeps), cels_require(ncurses)
  src/main.c        -- CEL_Build, CEL_Root, TUI_Engine_use
  .gitignore        -- build/, .cache/, compile_commands.json
```

### Generated CMakeLists.txt Template

```cmake
cmake_minimum_required(VERSION 3.21)
project(<name> VERSION 0.1.0 LANGUAGES C CXX)

include(FetchContent)
FetchContent_Declare(cels
    GIT_REPOSITORY https://github.com/Luke-42-studios/cels.git
    GIT_TAG        v0.2.0
)
FetchContent_MakeAvailable(cels)

include(CelsDeps)
cels_require(ncurses)

add_executable(<name> src/main.c)
set_target_properties(<name> PROPERTIES C_STANDARD 99 C_STANDARD_REQUIRED ON)
target_link_libraries(<name> PRIVATE cels cels-ncurses flecs::flecs_static)
```

### Generated src/main.c Template

```c
#include <cels/cels.h>
#include <cels-ncurses/tui_engine.h>

CEL_State(AppState, { int counter; });

CEL_Root(AppUI, TUI_EngineContext) {
    TUI_WindowState_t* win = CEL_WatchId(ctx.windowState, TUI_WindowState_t);
    if (win->state == WINDOW_STATE_READY) {
        AppState_t* app = CEL_Watch(AppState);
        (void)app;
    }
}

CEL_Build(App) {
    (void)props;
    AppState = (AppState_t){ .counter = 0 };

    TUI_Engine_use((TUI_EngineConfig){
        .title = "<Name>",
        .version = "0.1.0",
        .fps = 30,
        .root = AppUI
    });
}
```

## Tasks

### Task 1: Custom main() with Subcommand Dispatch

**File:** `tools/cels-cli/src/main.c`

- Add custom `main(int argc, char** argv)` that replaces the library's universal main
- Parse argv[1] for subcommands: `init`, `--help`, `--version`
- If `init <name>`: call scaffolding function and `return 0`
- If no subcommand: call `Engine_Startup() -> CELS_BuildInit() -> cels_run_providers() -> Engine_Shutdown()`
- Move existing `CEL_Build(CLI)` contents into a static `cli_build_init()` function, define `CELS_BuildInit()` to call it

### Task 2: Scaffolding Implementation

**File:** `tools/cels-cli/src/scaffolding.h` (header-only, included by main.c)

- `scaffold_project(const char* name)` function
- Creates `<name>/` directory, `<name>/src/` subdirectory
- Writes CMakeLists.txt from template (name substituted)
- Writes src/main.c from template (name substituted into title)
- Writes .gitignore
- Returns 0 on success, 1 on error (directory exists, write fails)
- Uses only POSIX: `mkdir()`, `fopen()`/`fprintf()`/`fclose()`

### Task 3: Build Verification

- Build cels-cli with `-DCELS_BUILD_CLI=ON`
- Verify `cels-cli init test-project` creates the directory with all 3 files
- Verify `cd test-project && cmake -B build && cmake --build build` compiles
- Verify `cels-cli` (no args) still launches the TUI
